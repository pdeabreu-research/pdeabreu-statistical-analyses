# pdeabreu-statistical-analyses

Reproducible Stata workflows for statistical analysis, model specification,
estimation (SEM-based, multilevel, and simulation-based approaches), and
robustness assessment across cross-sectional and longitudinal designs.

> **Note:** This repository contains anonymized, research-oriented analysis
> workflows. It does not include proprietary datasets, confidential materials,
> or publication-restricted code.

## Scope and Intended Use

This repository serves as a **methodological reference** illustrating how
complex statistical analyses are structured, estimated, and stress-tested in
applied research contexts.

It is not intended as a plug-and-play analysis package. Each workflow assumes
domain knowledge, careful modeling decisions, and researcher judgment.

## How to Read This Repository

- The `workflows/` directory contains **end-to-end Stata analysis pipelines**
  organized by modeling family.
- The `examples/` directory contains **lightweight, synthetic demonstrations**
  where needed to clarify structure.
- Each analysis emphasizes **model specification, assumptions, diagnostics,
  and robustness**, not just results.

Readers should treat this repository as a **research-grade reference**, not a
teaching tutorial or automated tool.
